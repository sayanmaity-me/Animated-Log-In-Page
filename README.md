# 🚀 Animated Login Page

A sleek, modern **Animated Login Page** crafted with pure HTML and CSS, featuring smooth animations and responsive design for a dynamic user experience.

## ✨ Features

- 🎨 **Pure CSS Magic:** No JavaScript, just clean, efficient CSS.
- 🔄 **Smooth Animations:** Engaging transitions for input fields and buttons.
- 📱 **Responsive Design:** Looks stunning on desktops, tablets, and mobile devices.
- 🌈 **Modern UI:** Minimalistic design with aesthetic fonts and cool icons.
- ⚡ **Optimized Performance:** Lightweight and fast-loading.

## 📂 Project Structure

```
Aimated login page/
├── index.html       # Main HTML file
└── style.css        # CSS for styling and animations
```

## 🚀 Getting Started

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/YOUR-USERNAME/animated-login-page.git
cd animated-login-page
```

### 2️⃣ Run the Project
- **Option 1:** Open `index.html` directly in your browser.
- **Option 2:** Using Live Server (recommended):
  ```bash
  npm install -g live-server
  live-server
  ```
